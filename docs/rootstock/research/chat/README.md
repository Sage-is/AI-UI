"Read, not run" marks a claim proven by reading code only. `plan:N` is line N of the approved Rootstock plan.

A chat turn leaves the browser as one POST and gets a task id back at once. The answer travels over Socket.IO, not over that HTTP response. Only an API caller without a session gets a real SSE stream. The privacy filter hangs on one function, and the code around that function has several holes.

## 3. Edge cases worth keeping

Marks: **K** carry over, **F** fix on the way, **D** dies with a cut feature.

1. **(K) The answer outlives the request.** The POST returns a task id and `response_handler` runs as an asyncio task keyed by the chat id, so closing the tab does not stop it. Stop calls `/api/tasks/stop/{task_id}` and the cancel handler saves the partial text; `utils/middleware.py:2230-2259`; `tasks.py:96-118,139-166`; `main.py:1872-1880`. Why: Cloudflare cuts an HTTP request at 100 s and legacy never holds one open; the Rootstock's SSE must keep generating after a drop (plan:128).
2. **(K) Every frame carries the whole text.** `{content}` is the full serialised blocks, not a delta; `utils/middleware.py:1935-1941`; the SPA replaces `message.content` (`app/src/lib/components/chat/Chat.svelte:1276-1278`). Why: the SPA needs this shape until it is deleted; long answers cost quadratic bytes, which the Rootstock's `block` and `tail` events avoid.
3. **(K) Stored text is HTML inside markdown.** `<details type="reasoning|tool_calls|code_interpreter">` blocks live in `message.content`; `utils/middleware.py:192-204,274-308`. The browser strips them before the next turn (`app/src/lib/components/chat/Chat.svelte:1651`) and the tasks regex them out (`utils/middleware.py:1456-1461`). Why: old chats hold this shape and the writer must keep it while Svelte reads them; the census holds no `<details>` count (unverified).
4. **(F) The server never writes `done`.** Only the browser sets it (`app/src/lib/components/chat/Chat.svelte:1319-1320`), and it refuses to send on a last message without it (`app/src/lib/components/chat/Chat.svelte:1400-1403`). In the July snapshot 9,103 messages carry `done` against 9,216 assistant replies; the cause of the gap is (unverified). Why: a tab closed mid-stream leaves a chat that cannot continue. Write `done`, `usage` and `error` when the stream closes.
5. **(F) Two writers share one blob.** The server upserts (`models/chats.py:238-263`) and the browser overwrites (`routers/chats.py:446`; `app/src/lib/components/chat/Chat.svelte:1021-1027`) with no version check, and `update_chat_by_id` hides failures (`models/chats.py:182-183`). Why: follow-ups, title and tags arrive after `done`, while the browser is saving. The plan's check on `updated_at` (plan:124) fits.
6. **(F) Errors flatten to 400 and a dropped upstream kills the task silently.** `main.py:1800-1803,1823-1826` turn every failure into 400, so an upstream 429 or 502 reaches API callers as 400. The read loop `async for line in response.body_iterator` (`utils/middleware.py:1770`) sits outside the per-line `try` (1785-1948), and `response_handler` catches only `CancelledError` (2230), so a connection reset should raise into an un-awaited task (`tasks.py:104-106`): no `done`, and no save while realtime save is off, its default (`env.py:328-330`) (read, not run). Why: the Trellis loop plan calls this route with `stream: false`, retries and backoff (`crm/docs/plans/loop.md:9` in the Trellis repo) and needs real status codes.
7. **(F) A stream error is shown, not stored.** The `{error}` chunk is emitted (`utils/middleware.py:1809-1821`) but no server patch records it; the browser sets `message.error` (`app/src/lib/components/chat/Chat.svelte:1822-1825`). Errors found before the stream do get stored (`main.py:1790-1798`). In the July snapshot 599 messages carry `error`. Why: a reload before the browser saves loses the reason, and the SPA then blocks the chat (`app/src/lib/components/chat/Chat.svelte:1404-1407`).
8. **(K) Reasoning has three entry points.** Field deltas named `reasoning_content`, `reasoning` or `thinking` (`utils/middleware.py:1834-1864`), eight inline tag pairs (1733-1742) and the end-of-stream finalizer, which also splits a stray end tag out of an unclosed block (110-159; `REASONING_END_TAG_RE`, 102-107). Four goldens pin them; `reasoning-field-closed-then-orphan` freezes a known leak on purpose (`scripts/smoke/chat-response-oracle.py:371-385`). A frozen bug: `tag_content_handler` also deletes literal `<<think>...>` spans (`utils/middleware.py:461-467`). Why: models differ, and the plan's single tag-aware buffer (plan:192) must pass all four goldens.
9. **(K) Tool rounds have quirks.** The cap is 10 and nothing tells the user it was hit (`utils/middleware.py:2008-2011`). Arguments go through `ast.literal_eval` before `json.loads` because some models emit Python dicts (2037-2042), then are re-dumped (2056-2058). Arguments are cut to the spec's keys (552-556). An unknown tool name yields a null result (2063-2087). In raw mode, calls and results return as Hermes-style tags (224-252; `docs/decisions/2026-08-08-raw-tool-call-form.md`). Why: each quirk keeps some model working.
10. **(K) The default tool mode is an extra model call.** Without `function_calling: native`, an opt-in model param (`main.py:1769-1778`), `chat_completion_tools_handler` asks the task model to pick tools as JSON, runs them before the answer and appends `Tool X Output:` to the last user message (`utils/middleware.py:739-892`, 861-864). Space replies depend on this mode (`routers/spaces.py:351-357,389-394`), and 18 of 332 `model` rows carry `toolIds`. Why: a native-only loop would leave those agents without tools in non-streamed Space replies.
11. **(K) Retrieval costs one more model call.** Any turn with `files` first calls `generate_queries`, non-streamed (`utils/middleware.py:1037-1062`); failure falls back to the last user message (1061-1065). `task.query.retrieval.enable` is true in both census databases. Why: it adds a full round trip before the first token on every Space or knowledge turn.
12. **(F) Knowledge failure is silent.** `query_collection` logs and returns empty (`retrieval/utils.py:329-331,355-358`), `get_sources_from_items` swallows the rest (727-728) and the Chroma driver answers None to any error (`retrieval/vector/dbs/chroma.py:98-99`). The model answers ungrounded and the turn succeeds. Why: that is how every knowledge base came to return nothing with a 200 (`TODO.md:148-156`).
13. **(F) The system prompt joins late, and twice for Space agents.** `apply_model_system_prompt_to_body` runs inside the provider router, after the filter (`routers/openai.py:928-929`; `routers/ollama.py:1371-1372`). `add_or_update_system_message` prepends with no dedup (`utils/misc.py:152-166`), and a Space reply already puts the raw prompt in the messages (`routers/spaces.py:341-345`), so the prompt should appear twice (read, not run). Why: a privacy hole and a prompt bug in one line.
14. **(K) Model params beat chat controls.** `apply_params_to_form_data` copies chat params into the body (`utils/middleware.py:1108-1140`), then the router overwrites them with the model row's params (`routers/openai.py:928`; `utils/payload.py:48-55`). Ollama gets `options` instead (`utils/middleware.py:1123-1125`). Why: an agent's temperature wins over the user's slider, and reversing that would change every agent.
15. **(K) The access gate reads `role == "user"`.** Facilitator and temporary accounts skip `check_model_access` and the `/api/models` filter (`main.py:1673,1742`; `utils/chat.py:219`; `routers/openai.py:731,932`), while a raw base model with no `model` row is admin-only (`routers/openai.py:943-948`). `utils/auth.py:309` lists the four roles. Why: the identity matrix must say what a facilitator may call, so decide it rather than copy it by accident.

17. **(F) Tool-server calls are not escaped.** Query values are joined raw (`utils/tools.py:404-406`) and path values are inserted raw (401-402). `session` auth forwards the user's JWT to the tool server (77-80). Why: model-chosen text lands in URLs, and a session token leaves the box.

The server fills `{{CURRENT_DATE}}`, `{{CURRENT_TIME}}`, `{{CURRENT_DATETIME}}`, `{{CURRENT_WEEKDAY}}`, `{{USER_NAME}}` and `{{USER_LOCATION}}` (`utils/task.py:49-87`; `utils/payload.py:12-38`). Why: any of the 55 `model` rows with `params.system` may use them (unverified).
19. **(D) Dead and broken web-search remnants.** `features.web_search` is a live `NameError` (`utils/middleware.py:1257-1260`; `TODO.md:1470`). `routers/tasks.py:67,125,151,443` read `config.ENABLE_SEARCH_QUERY_GENERATION`, which neither `config.py` nor `main.py:1392-1396` defines, and `AppConfig.__getattr__` raises on an unknown key (`config.py:241-243`), so `GET /api/v1/tasks/config` should fail (read, not run). Why: chat blobs carry copies of document text, and the shape is read in two places.
26. **(K) The webhook sends the real reply.** `notify_webhook_if_offline` posts the reversed text to the user's own URL when no session is active (`utils/middleware.py:710-729`). 27. **(F) Tool arguments leak on the follow-up.** `finish_stream` makes the arguments real (`privacy/hooks.py:159-164`), the next round replays them in `assistant.tool_calls` (`utils/middleware.py:345-352,2091-2102`), and `_rewrite_message` skips `tool_calls` (`privacy/hooks.py:105-113`; `utils/chat.py:209-211`). 29. **(K) The filter covers chat completions only.** Embeddings, images, speech, the raw `/openai` and `/ollama` routes and any local, Ollama, arena or pipe model skip it (`docs/federation.md:91-93`; `privacy/hooks.py:52-56`). ## 5. Rootstock equivalent

- **Ops.** `chat_turn` is an async-generator op served as SSE (plan:128). Beside it: `chat_stop`, `ask` (non-streamed, one receipt), chat CRUD (`chat_get`, `chat_list`, `chat_rename`, `chat_move`, `chat_pin`, `chat_archive`, `chat_delete`, `chat_share`) and `models_list`. Title, tags and follow-ups are internal jobs of `jobs/`, not routes. A few dozen ops replace the 66 non-Ollama decorators (the plan's total target is about 95 ops), and the Ollama 40 go to zero.
- **`compat/` keeps one chat route.** `POST /api/chat/completions` stays for API callers with today's JSON and SSE shapes, including the `sources` extension (`utils/middleware.py:1659-1670`) and the `privacy.known` hint (`main.py:1766`). It must return the provider's own status instead of 400 (edge case 6) and take the same body as the Trellis loop plan (`stream: false`, `response_format`, no `tool_ids`).
- **Turn assembly, in `conversations/chat/turn.py`.** One fixed order: agent system prompt with variables, folder prompt, history, knowledge hits (the `knowledge_search` op), tool specs, then the privacy walk, then the provider. Putting the system prompt before the walk fixes `routers/openai.py:929`. Model params override chat controls, as today (edge case 14). The retrieval-query call becomes a per-knowledge-base option, because it adds a model call to every grounded turn (edge case 11).
- **Blocks, in `conversations/chat/shape.py`.** `text`, `reasoning`, `tool_use` and `tool_result`, plus one tag-aware reasoning buffer that passes the four reasoning goldens (edge case 8). `<details>` HTML is written only at the save boundary and by `compat/`, so old chats and the Svelte chat keep working. The legacy block code is about 420 lines (`utils/middleware.py:98-378,381-523`); the plan's whole `conversations/` cap is 2,700.
- **Provider kinds, in `providers/kinds/`.** `openai` covers the first four rows of the table above and exports `stream`, `models` and `embed`. `anthropic` and `responses` are new and port the Tinker files (444 and 285 Rust lines; 1,584 across the five files). - **Stable connection ids.** Connections are three parallel lists in `config` (`routers/openai.py:229-258`). - **Privacy, in `privacy/walk.py` and `mapper.py`.** `engine.py`, `rules.py` and `shapes.py` come over unchanged (545 lines, adapted). The walk covers system prompt, text, `ToolUse.input` strings and `ToolResult` (fixes `privacy/hooks.py:105-113` and the leak in edge case 27). Four calls need a decision that the code does not make today. Reasoning text: reverse it, or keep stand-ins on screen as now. Tool servers: the plan says stand-ins, but a tool that looks up a real person by name cannot work on one, while today both the prompt-mode and native paths hand tool servers real values (`utils/chat.py:169-170`; `privacy/hooks.py:120-133,159-164`). The mapper cache also needs the plan's rule, since the current one only drops on its own inserts (`privacy/mapper.py:14-37`).
- **Receipts.** One row per model call, including each tool round, each task and each retrieval query: today the browser holds the only usage figures and stores them on 3,819 of 16,654 messages (July snapshot). Budgets and `aggregates` read from this table, so it replaces the lost counts rather than copying a legacy table.
