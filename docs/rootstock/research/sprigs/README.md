## 2. What really runs

The supervisor is a control plane. It spawns and stops children and writes config. No request passes through it. A grafted capability is reached by plain HTTP to a loopback URL that a `*_dispatch.py` module wrote into config.

1. **Boot blocks on the Sprigs.** The lifespan builds the supervisor and awaits `start()` before it yields (`app/backend/sage_is_ai/main.py:741-742,755`). `start()` takes the flock, checks config, runs `_reconcile`, then probes the registry (`app/backend/sage_is_ai/sprigs/supervisor.py:827-849`). `_reconcile` re-grafts each `state.json` entry in turn and waits on each child's health (`:1012-1108`). The deadlines are ceilings, not measurements: a GGUF embedder, the reranker, STT, Tika and Docling add up to 240+240+120+180+300 = 1,080 s (`:431,463,491,526,561`). The registry probe adds up to 4 s (`:906`). Uvicorn takes no connection until lifespan startup returns (unverified: its source is not on this host), so `/health` and the HEALTHCHECK (`Dockerfile:408`) wait too.
2. **Stale config is reset at import, before the lifespan.** Three backstops clear a persisted loopback URL whose key is the sentinel `sprig-local` (`app/backend/sage_is_ai/sprigs/embedding_dispatch.py:19`): embedding at `app/backend/sage_is_ai/main.py:1186-1213`, reranker at `:1224-1242`, STT at `:1360-1378`. Reconcile then writes the fresh port. Tika and Docling persist a loopback URL too (`app/backend/sage_is_ai/sprigs/tika_dispatch.py:25`, `app/backend/sage_is_ai/sprigs/docling_dispatch.py:25`) and have no backstop.
3. **Graft, from the panel to a healthy child.** A page action or `POST /graft` reaches `graft_sprig`, which checks the catalog allowlist (`app/backend/sage_is_ai/routers/sprigs.py:131-138`) and calls `supervisor.graft` (`app/backend/sage_is_ai/sprigs/supervisor.py:1385-1538`). In order:
- The name and capability must match the catalog (`:1386-1390`).
- `_graft_refusal` runs before any byte moves, then the host arch's override is laid over the spec (`:1403-1417`).
- `server: deliver` goes to `_deliver` (`:1421-1422`); `server: none` goes to `_enable` (`:1433-1434`).
- A live child of the same name returns as it is (`:1437-1440`), so a tag bump never reaches a running child.
- `_build_argv` picks the module and argv from the `server` kind (`:1443`).
- An `oci-artifact` entry runs `artifact.ensure` first, so a failed pull leaves the running cultivar alone (`:1445-1477`).
- Embedding, reranker and STT stop any other rooted cultivar of that capability (`:1486-1493`).
- The port comes from `_reserve_loopback_port` (`:1495`). The child starts in its own session with stdout and stderr on DEVNULL (`:1498-1522`).
- `_wait_until_healthy` polls `health_url` every 0.25 s with a 1 s timeout until HTTP 200. It raises at once if the child exited (`:1555-1574`). On any failure the child is terminated and the error re-raised (`:1525-1529`).
- `_persist_state` writes `state.json` (`:1531`).
4. **After the child is healthy, the router dispatches.** It clears the recorded error (`app/backend/sage_is_ai/routers/sprigs.py:166`) and walks a capability ladder that calls the matching `point_*_at` (`:168-319`). A failure is recorded on the volume and answers 503 (`:152-163`).
5. **Delivery, `artifact.ensure` (`app/backend/sage_is_ai/sprigs/artifact.py:353-469`).** Three seed modes. `app-dir` (8 entries) extracts into a container-layer target such as site-packages or `/usr/local/bin` (`:380-408`). `model-dir` (10 entries) extracts to `<root>/extracted` on the volume (`:410-414,453-463`). `chroma-onnx` (the MiniLM entry alone) copies into chromadb's cache (`:237-264,465-469`).
- `_obtain_tar` prefers the tar cached on the volume as `<name>-<tag>.tar.zst`. A hit is re-hashed and its signature re-checked every time (`:298-316`). A miss pulls into `.staging/`, checks the sha256 pin and the signature, then promotes the tar and deletes older-tag tars (`:326-350`).
- Extraction runs `tar --use-compress-program=zstd` (`:227-234`). The image installs gnutar and zstd for it (`Dockerfile:143-153`). The whole pull has one 300 s budget (`app/backend/sage_is_ai/sprigs/artifact.py:59,124-126`).
- Extraction is skipped only if the sentinel exists and `.delivered-tag` equals the catalog tag (`:386-391,427-431`). A `model-dir` upgrade wipes `extracted/` first (`:447-450`).
6. **The pull, `oci.py` (new in 3.2.1, replaces the `oras` CLI).** It fetches the manifest, then streams each titled layer through a byte counter and a sha256 (`app/backend/sage_is_ai/sprigs/oci.py:120-200`). Auth is an anonymous Bearer token only (`:71-80,134-153`). It reads layer titles, digests and sizes and ignores layer media types.

7. **Signing, `minisign.py` and the policy in `artifact.py`.** `minisign.py` checks the standard format offline: Ed25519 over the blake2b-512 prehash (`ED`) or the raw file (legacy `Ed`), a matching key id, and a second signature over the trusted comment (`app/backend/sage_is_ai/sprigs/minisign.py:102-145`). The policy (`app/backend/sage_is_ai/sprigs/artifact.py:166-224`): a present signature is always verified; one is required when the entry sets `signed` or `SPRIG_REQUIRE_SIGNED` is on; the key comes from the entry's `pubkey`, then `SPRIG_MINISIGN_PUBKEY`, then the baked key.

## 3. Edge cases worth keeping

**The proxy, `expose.proxy` (plan:208,85,112).** The specs come close once: a `dev-` Sprig's frontend requests are proxied by the rootstock (`../BONSAI/sprig-spec/v1.md:125`). - **Body caps the proxy must match or stream past.** rpc 16 MiB (`lib.rs:119`); files 25 MiB plus 1 MiB (`lib.rs:123`; `../AI--Tinker.Click/store/src/files.rs:9`); merge 2 GiB (`lib.rs:129`); errors and feedback 64 KiB (`lib.rs:151,155`).
- **Mount verbatim.** The sign-in page posts to the absolute path `/v1/auth/confirm` (`lib.rs:675`), so that path must resolve at the box root. The desktop app builds `{api_url}/v1/...` (`../AI--Tinker.Click/src-tauri/src/commands/update.rs:21`), so `api_url` may carry a base path, but the Confirm button cannot.
- **List patterns, not the prefix.** Another core route may want `/v1/` (an OpenAI-compatible base URL is conventionally `/v1`).
- **Own the paths when the child is down.** The legacy catch-all answers an unmatched path, except `.js` and `api/...`, with 200 and the app shell (`app/backend/sage_is_ai/main.py:469-488,2578`). The desktop health probe would read that HTML as a server. The proxy answers 503 JSON itself. `OWNED` is compiled per release (plan:112) while `expose` is runtime data, so reserve the prefix in `OWNED` and resolve beneath it.
- **Stream.** The caps run to 2 GiB. Django's ASGI handler reads a request body in full before the view runs (unverified: Django is not on this host), which argues for proxying at the seam. Cloudflare limits request bodies well below 2 GiB (external, unverified), so a large `/v1/merge` may need another path.
- **Headers.** Forward `Authorization`. Drop `Cookie` so the box session never reaches a partner binary, and drop `Set-Cookie` from replies. Keep the callback page's `Content-Security-Policy`, `X-Frame-Options` and `Cache-Control: no-store` (`lib.rs:620-627`); the legacy CORS and compression middleware must not wrap them (plan:112).
- **Skip the box's session and CSRF layers.** The child authenticates with its own bearer tokens. Route by path before any identity is read (plan:114).
- **Check collisions at load.** Reject an `expose` path under a core prefix (`/api/`, `/mcp`, `/pages`, `/static`, `/themes`, `/ui`, `/openai`, `/ollama`, `/ws`). No check exists, because no Sprig has routes, and the marketplace lanes would let others extend the catalog (`TODO.md:646-647`).
- **Abuse surface.** `POST /v1/errors` and `/v1/feedback` accept anonymous writes into capped tables of 10,000 and 50,000 rows (`../AI--Tinker.Click/docs/SERVER.md:31-36,48-52`). Registering is open, gated by `TENKTS_SERVER_ALLOW`. That exposure exists under Caddy today; the proxy moves it onto the box's origin. The callback page is the only HTML the server serves, and its CSP is `default-src 'none'` (`lib.rs:609-630`).
